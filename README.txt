CORBETT JUNGLE SAFARI — FREE WEBSITE STARTER

FILES
- index.html: the complete responsive Hindi + English website
- script.js: WhatsApp enquiry form and contact settings

BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Replace WHATSAPP_NUMBER = "91XXXXXXXXXX" with your business WhatsApp number (country code + number, digits only).
3. Replace DISPLAY_PHONE and DISPLAY_EMAIL with your real contact details.
4. Open index.html in a browser to preview.

FREE HOSTING WITH GITHUB PAGES
1. Create a free account at https://github.com/
2. Create a new public repository, e.g. corbett-jungle-safari
3. Upload index.html and script.js to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the Pages URL to appear. It will look like https://YOUR-USERNAME.github.io/corbett-jungle-safari/

IMPORTANT
- Hosting is free on GitHub Pages for a public repository. A custom domain is optional and usually costs money.
- This is an enquiry website, not a live booking/payment system. The form sends the visitor's enquiry to your WhatsApp.
- Do not claim a safari slot is confirmed until it has been verified and booked through the official authorised process. Availability, zones, rules and fees can change.
- Images are loaded from Unsplash over the internet; an internet connection is needed to display them.
- Replace all sample contact information before sharing the website.
